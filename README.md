## 5. Scenario-Based Demo & Practice Questions

### Question 1
In Oracle B2B Service, which component is configured to monitor time-based service commitments (such as First Response Time or Resolution Time) and escalate when thresholds are breached?

A) Queue Threshold Monitor
B) Service Milestone within a Service Level Agreement (SLA)
C) Assignment Manager Rule
D) Omnichannel Capacity Rule

- **Correct Answer**: `B) Service Milestone within a Service Level Agreement (SLA)`
- **Technical Explanation**: Service milestones defined in Service Level Agreements (SLAs) track critical duration metrics (like Initial Response or Resolution) against business operating hours and initiate warning/escalation actions.

---

### Question 2
How does Omnichannel routing distribute incoming real-time customer interactions to customer support agents in Oracle B2B Service?

A) Based on agent presence, configured capacity rules, and agent skill sets
B) Randomly to any active user in the system
C) Strictly by chronological alphabetical order of agent usernames
D) By assigning all requests to the queue supervisor

- **Correct Answer**: `A) Based on agent presence, configured capacity rules, and agent skill sets`
- **Technical Explanation**: Omnichannel routing evaluates the agent's current availability (presence state), remaining workload capacity, and matching qualification/skills before assigning an incoming interaction.
